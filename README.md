# Remix of SyncShow Hub

**"Build a complete Full-Stack Streaming Platform called 'SyncShow'.



Visual Theme: Midnight Blue (#0a0e1a) background, Glowing Red accents, Glassmorphism effects.

Navigation: Hidden Sidebar (Side Drawer) containing Profile, Movies, TV, Sports, Watch2Gether, and DMs.

Home Page: Cinematic hero section with 'syncshow' neon title in center + movie grid below.

Streaming Page: Integrated player for 'doopstream.co' links. Sidebar for Group Chat, Camera/Mic toggles, and a 'Schedule Event' button with countdown.

Logic & Backend: Connect Supabase for Auth. Create tables for: Movies (link, title), TV (m3u, country), Matches (scores, time).

Admin Panel: A secure page to add movies/channels/matches.

Features: Real-time DMs (1:1 chat), and Block/Report system.

Everything should be mobile-responsive and ultra-modern."**
